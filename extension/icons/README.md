# Extension icons

Add these PNG files for Chrome Web Store and toolbar:

- `icon16.png` — 16×16
- `icon32.png` — 32×32
- `icon48.png` — 48×48
- `icon128.png` — 128×128

Use a simple "V" or book/word mark in your brand orange (#F59E0B) on dark (#0F0F1A) or transparent. Chrome will use 128 for the store and 48 for the extension management page; 16 and 32 for the toolbar.
